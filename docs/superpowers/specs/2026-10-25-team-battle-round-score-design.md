# 청백전 경기 총합 점수 및 개인 승률 설계

## 의도

청백전의 팀 점수는 완료된 개별 경기 승수의 총합을 나타내고, 개인 기여도는 본인이 완료한 경기 중 승리한 비율을 나타낸다.

## 동작

- 개인 기여도는 `개인 승리 경기 수 / 개인 완료 경기 수 * 100`으로 계산한다.
- 4경기 4승은 100%, 4경기 2승은 50%로 표시한다.
- 임시 선수는 기존처럼 팀 기여도 명단에서 제외하되 경기 결과에는 반영한다.
- 완료된 각 경기의 승리팀에 팀 점수 1점을 누적한다.
- 동점 경기는 어느 팀에도 승점을 주지 않고 무승부 경기로 집계한다.
- 관리자와 사용자 공유 화면은 동일한 공용 계산 결과를 사용한다.
- 화면의 완료 수와 무승부 수는 경기 단위로 표시한다.

## 접근 방식

- 선택: `lib/domain/team-battle.ts`의 공용 결과 계산은 완료 경기 승수를 누적하고, 기여도 컴포넌트는 개인 전적을 분모로 사용한다.
- 대안: 각 화면에서 별도로 라운드 점수를 계산할 수 있으나 관리자와 공유 화면 간 불일치 위험이 있어 사용하지 않는다.
- 데이터베이스 구조와 저장된 경기 점수는 변경하지 않는다.
